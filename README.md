📄 Descrição dos Arquivos
app.py: Arquivo principal da aplicação, responsável por iniciar e executar o programa.
classeprincipalcatalogo.py: Arquivo destinado à implementação da classe principal do catálogo.
csfilme1.py: Módulo relacionado às funcionalidades de filmes.
csserie1.py: Módulo relacionado às funcionalidades de séries.
csusuario2.py: Módulo relacionado às funcionalidades de usuários.
.gitignore: Define os arquivos e diretórios que devem ser ignorados pelo Git.
__pycache__/: Diretório gerado automaticamente pelo Python para armazenar arquivos de cache de bytecode.
README.md: Arquivo de documentação do projeto.
⚙️ Tecnologias Utilizadas
Python 3
Git (para controle de versão)
🚀 Como Executar
Instale o Python 3, caso ainda não esteja instalado.
Abra o terminal na pasta do projeto.
Execute o comando:
bash
python app.py


Se necessário, utilize python3 app.py.
